## 4th November 2026: 4 Hours
 So this was my first time creating in onshape, so i had to learn a lot about it, but the AI assistant in onshape itself came very much in handy, like it cannot directly access my files and create things but when i was like " I want to split this body into two halves" The assistant told me how to do so.
I mean it was pretty dumb of me coz there literally was a tool named "Split" But there are so many tools in there its overwhelming.
Anyways, it was quite a task to find the cad models of the electronics i was using in my project to reference the measurements off of. 
Found the ESP32 and Oled very easily but damn it took me time to find the SD card module. 
In the end i did find them all and made a pretty simple but practical model using only basic stuff like extrude and fillet only probably lol.
I actually had fun in the end like at the start it was kind of a tedious job but in the end where i started to make the unnecessary engravings it was kinda fun. 
Made all slots for the ports and jacks, left plenty space for wirings and other stuff.
Gonna ship after making the BOM then boom gonna get to making.
